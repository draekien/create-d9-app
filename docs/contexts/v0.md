# v0 scope

Read before adding a feature, tool, prompt, flag, or create path while v0 is unreleased.

- v0 scaffolds only the default stack: TanStack Start, Biome, TypeScript 7, pnpm, Lefthook, Turborepo, shadcn, Tailwind, Motion.
- v0 supports only `pnpm create dstack`; `npm create`, `yarn create`, and `bun create` come later.
- v0 offers no tool alternatives; do not build them into v0.
- Structure v0 so tool alternatives and other create paths can be added later without a rewrite.

# v0 scope

Read before adding feature, tool, prompt, flag, or create path while v0 unreleased.

- v0 scaffolds default stack only: `@tanstack/*`, Biome, TypeScript 7, pnpm, Lefthook, Turborepo, shadcn, Tailwind, Motion.
- v0 create paths: `npm create`, `pnpm create`, `yarn create`, `bun create` all run the CLI. Generated project + install always pnpm. Package manager choice after v0.
- v0: no tool alternatives. Do not build them.
- Structure v0 so tool alternatives + other create paths can be added without rewrite.
- v0 may release without upgrade-dependencies skill (ADR 0001). Skill ships before v1.
